# Archive

Entries removed from the [main list](README.md) because the repository is archived, the project is no longer maintained, or the product is gone. Each entry states the reason.

## Archived

- [Azure LLM Evaluation Samples](https://github.com/Azure-Samples/llm-evaluation) - Prompt Flow and Azure AI projects demonstrating hosted evals. The repository is archived.
- [BIG-bench](https://github.com/google/BIG-bench) - Collaborative benchmark of 200+ tasks probing reasoning and commonsense. The repository is archived.
- [PromptBench](https://github.com/microsoftarchive/promptbench) - Unified evaluation framework for adversarial prompt robustness. The repository is archived.
- [ToxiGen](https://github.com/microsoft/TOXIGEN) - Machine-generated dataset for implicit hate speech detection. The repository is archived.

## Unmaintained

- [AlpacaEval](https://github.com/tatsu-lab/alpaca_eval) - Automatic evaluator for instruction-following models using LLM judges validated against human annotations. No commits since 2025-08.
- [ARTKIT](https://github.com/BCG-X-Official/artkit) - Framework for automated prompt-based testing and red teaming of generative AI applications. No commits since 2025-03.
- [AutoRAG](https://github.com/Marker-Inc-Korea/AutoRAG/tree/main/legacy) - RAG AutoML tool that evaluates module combinations to select a pipeline for a dataset. The original tool is in maintenance mode in the `legacy` directory; the repository now hosts a different product.
- [OpenAI Evals Demo Evals](https://github.com/withmartian/demo-evals) - Templates for extending OpenAI Evals with custom datasets. No commits since 2023-11.
- [Phoenix AI Chatbot](https://github.com/Arize-ai/phoenix-ai-chatbot) - Next.js chatbot with Phoenix tracing and evaluation jobs. No commits since 2024-08.
- [R-Eval](https://github.com/THU-KEG/R-Eval) - Toolkit for evaluating RAG workflows on domain knowledge. No commits since 2024-04.
- [RAGEval](https://github.com/OpenBMB/RAGEval) - Generates domain corpora, questions, and reference answers for RAG evaluation. No commits since 2025-04.
- [UpTrain](https://github.com/uptrain-ai/uptrain) - Evaluation suite with 20+ preconfigured checks. No commits since 2024-08.

## Discontinued

- [Agenta](https://github.com/Agenta-AI/agenta) - Formerly an LLM evaluation and prompt management platform. The project is now a workspace for building agents.
- [Error Analysis & Prioritizing Next Steps](https://www.youtube.com/watch?v=bWkQk5_OG8k) - Andrew Ng talk on slicing traces to focus eval work. The video is unavailable.
- [GenAI Notes](https://github.com/eugeneyan/genai-notes) - Notes on generative AI systems and evaluation. The repository returns 404.
- [Humanloop](https://humanloop.com/) - Prompt management with human-in-the-loop evals. The site now only announces that Humanloop joined Anthropic.
- [Lilac](https://github.com/lilacai/lilac) - Dataset exploration and curation tool. The repository no longer hosts the project.
- [LLM Agents Benchmark Collections](https://llmbench.ai/) - Aggregated agent leaderboard. The domain is for sale.
- [Maxim AI](https://www.getmaxim.ai/) - Formerly an evaluation and observability platform. The site now presents an AI gateway.
- [Orq.ai](https://orq.ai/) - Formerly an LLM operations platform with evaluation workflows. The site now presents an AI gateway.
- [Parea AI](https://www.parea.ai/) - Developer tools for evaluating and monitoring LLM apps. The site returns HTTP 402.
- [Patronus AI](https://www.patronus.ai/) - Formerly an evaluation platform with LLM judges. The site no longer describes an evaluation product.
- [VisualToolBench](https://github.com/showlab/VisualToolBench) - Benchmark for visual tool use by multimodal models. The repository returns 404.
